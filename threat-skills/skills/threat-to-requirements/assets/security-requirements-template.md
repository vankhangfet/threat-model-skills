## How to use
- Coding agents and developers: read the requirements for the component you are changing before
  you change it. Reference SR ids in commits and merge requests.
- A requirement is **Required** until its threats are Mitigated in Threat Dragon, then **Implemented**.
  **Retired** requirements stay for history.
